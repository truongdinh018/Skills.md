# Ví dụ PASS (minh họa format — thay bằng case thật của phòng ban)

## Bối cảnh

- Người thực hiện: [vai trò]
- Công đoạn: [tên]
- Bằng chứng đã có: biên bản ký đủ, ảnh hiện trường rõ

## Kết quả kiểm tra (rút gọn)

| ID | Mục | Severity | Kết quả | Ghi chú |
|----|-----|----------|---------|---------|
| CHK-01 | […] | must | Pass | Ảnh đính kèm |
| CHK-02 | […] | must | Pass | Biên bản số … đã ký |

**Hold points:** mở  
**Verdict comply:** `COMPLIANT`
